Trophy Guide is an offline guide and tracker for all 55 GTA 6 PS5 trophies: official names, descriptions and grades, cited guides, platinum roadmap, missable flags, filters and spoiler settings.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
